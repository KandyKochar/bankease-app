# BankEase

A modern digital banking landing page built with HTML, CSS, and JavaScript, featuring an interactive financial dashboard UI.

## Overview

BankEase is a responsive single-page application that simulates a digital banking platform. It showcases a full marketing landing page with a feature overview, an interactive account dashboard, investment tools, and a contact section — all built with vanilla web technologies and Font Awesome icons.

## Features

- **Hero Section** — Animated call-to-action with tagline and banking imagery
- **Features Grid** — Highlights of advanced security, mobile banking, instant transfers, and smart analytics
- **Interactive Dashboard** — Account overview with balance display, quick-action buttons, and recent transaction list
- **Investment Tools** — Portfolio overview and investment options UI
- **Contact Section** — Contact form with validation
- **Responsive Navigation** — Mobile hamburger menu with smooth scroll
- **Animated Scroll Effects** — Elements animate into view as the user scrolls
- **Login / Register Modals** — Authentication UI flow

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Responsive layout, gradients, animations |
| JavaScript (ES6) | DOM interactions, scroll animations, modal logic |
| Font Awesome 6 | Icon library |

## Installation

No build step required — this is a static single-page application.

```bash
# Clone the repository
git clone https://github.com/KandyKochar/bankease-app.git

# Open in browser
open bankease.html
```

Or simply open `bankease.html` in any modern browser.
